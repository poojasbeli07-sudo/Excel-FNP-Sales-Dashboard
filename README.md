# Excel-FNP-Sales-Dashboard
Interactive Excel Sales Dashboard using Power Query, PivotTables, PivotCharts, Slicers and Power Pivot.

## Project Overview

An interactive sales dashboard created using Microsoft Excel to analyze
sales performance, revenue trends, order volume, delivery time and
product performance.

## Tools & Technologies

- Microsoft Excel
- Power Query
- Power Pivot
- PivotTables
- PivotCharts
- Slicers
- Timelines
- Excel formulas

## Key KPIs

- Total Orders
- Total Revenue
- Average Revenue
- Average Order-Delivery Time

## Dashboard Analysis

The dashboard provides analysis of:

- Revenue by Occasion
- Revenue by Category
- Orders by City
- Revenue by Month
- Revenue by Top 5 Products
- Revenue by Hour
- Order and Delivery Date trends

## Data Preparation

Power Query was used for:

- Data cleaning
- Data type transformation
- Date transformation
- Creating Month Name and Hour fields
- Calculating Order-to-Delivery days
- Data preparation for analysis

## Interactive Features

The dashboard includes:

- Occasion slicer
- Order Date timeline
- Delivery Date timeline
- Interactive PivotCharts
- KPI cards

## Project Objective

The objective of this project is to demonstrate practical Excel
data-analysis and dashboard-building skills that can be applied to
business intelligence and reporting use cases.
